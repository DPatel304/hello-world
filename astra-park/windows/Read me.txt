ORLIS PLAY for Windows
======================

INSTALL (once)
1. Unzip this whole folder anywhere - Downloads is fine. Setup copies the
   game into a place of its own, so you can delete this folder afterwards.
2. Double-click "Set up Orlis Play".
   If Windows says "Windows protected your PC", click "More info", then
   "Run anyway". It says that about anything downloaded that isn't from a
   big publisher.
3. A "Orlis Play" icon appears on your desktop and in the Start menu.
   That's the last time you need to install anything: see UPDATES below.

ALREADY HAD IT UNDER AN OLDER NAME?
Orlis Play is the same game with a new name. Nothing to do: the next time
the old icon starts it, the icons and the music folder are renamed to
"Orlis Play", songs and all. Scores and settings carry over.

MUSIC
Setup puts a "Orlis Play Music" folder shortcut on your desktop. Drop any
songs in it - MP3, M4A, WAV, FLAC or OGG - and the game plays them,
shuffled, the next time it starts. Remove a song by deleting it. With no
songs there, the game plays its own built-in music.

PLAY
- Double-click "Orlis Play". It opens full screen, ready to go: no camera
  question, and the music starts by itself.
- The laptop needs to be online when the game starts, because it downloads
  the body-tracking model.
- A small black window may flash for a moment when it starts. That's the
  launcher checking for updates.
- Point at something and wave to pick it.
- Or use a TV remote (one that plugs into the laptop): arrows to move, OK to
  pick, Back to go back. The laptop's arrow keys, Enter and Esc work too.
- Pause: both hands above your head, or Back.
- Leave full screen: F11.   Quit: Alt+F4.

UPDATES
Automatic. Each time the icon starts the game, it checks GitHub for a newer
version and installs it first - a new version is picked up within about a
minute of being published. If the laptop is offline it just opens the copy
it already has. To see what happened on the last start, open
%LOCALAPPDATA%\AstraPark\last-update.txt.
Scores and settings are kept across updates.

REMOVE
Delete the "Orlis Play" icon from the desktop and the Start menu, then paste
%LOCALAPPDATA%\AstraPark into the File Explorer address bar and delete that
folder.

IF YOU SEE A YELLOW BAR
"You are using an unsupported command-line flag: --use-fake-ui-for-media-stream"
That flag is what skips the camera question, and it only applies to the
Orlis Play window. The launcher now hides the bar; if it ever shows, click
the X to close it.
